## Generated Documents

Your CV or resume content belongs to you. Documents generated with VECTRA do
not need to use the LPPL, display attribution, include a watermark, or publish
their source merely because VECTRA was used to create them.

## Modifying the Template

You may modify VECTRA for your own needs. If you distribute a modified template,
follow the LPPL requirements for identifying changes and distinguishing the
modified work from the official maintained version.

## Sharing and Citation

The simplest way to share VECTRA is to link to the official repository. A
`CITATION.cff` file is provided so GitHub can generate a citation automatically.
Citation is appreciated when discussing the template, but it is not required in
documents generated with VECTRA.

## Questions and Improvements

Questions, corrections, and improvement proposals are welcome through GitHub
Issues. For substantial changes, open an issue before preparing a pull request
so the design direction can be discussed first.
